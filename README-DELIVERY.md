# N1S — полный автономный проект (сборка 24.07.2026)

Это ПОЛНЫЙ проект: все конфиги + `public/` + `src/` + `package.json`.
Годится и для импорта в Blink как новый проект, и как база для переезда
на свой хостинг, и как резервная копия.

Внутри уже применены изменения из CHANGES.md:
- 7 файлов заменены на исправленные версии (PageBackground, TabBar,
  Assistant, Metrics, Tasks, Settings, index.tsx)
- 14 мёртвых файлов шаблона отсутствуют (login.tsx, Shell.tsx,
  AppSidebarShell, shared-app-layout, components/ui/*, sample-config,
  widget-registry)
- package.json не тронут

## Чего здесь НЕТ (и почему)

1. **Картинки `public/hero-statue.jpg` и `public/dashboard-bg.jpg`** —
   бинарники нельзя передать через текстовый дамп терминала. Сборка и
   импорт от этого НЕ ломаются — просто фон логина и внутренних страниц
   будет пустым, пока файлы не добавлены. Скачай их с живого превью
   (n1s-dashboard-p69j91xs.blinkusercontent.com/hero-statue.jpg и
   /dashboard-bg.jpg) и положи в `public/`.
   `hero-mountain.jpg` — неиспользуемый остаток шаблона, не нужен.

2. **`bun.lock`** — лок-файл, пересоздаётся сам при установке зависимостей.

3. **`.env.local`** — не дампился. ВАЖНО при переносе на свой хостинг:
   `src/blink/client.ts` в качестве фолбэка зашит на СТАРЫЙ проект
   (`n1s-business-app-c5q4aqdi`). На хостинге обязательно задать env:
   `VITE_BLINK_PROJECT_ID=n1s-dashboard-p69j91xs` и актуальный
   `VITE_BLINK_PUBLISHABLE_KEY` — иначе приложение будет ходить в базу и
   auth старого проекта. При импорте в Blink платформа подставляет свои
   env сама.

4. **`index.html`** — его в проекте и не было: TanStack Start генерирует
   HTML сам. Это норма, не потеря.

5. **Скрипт Blink picker в `__root.tsx`** — обфусцированный base64-блок,
   служебный инструмент IDE Blink (не код приложения); ранее уже был
   опознан как источник cross-account бага и удалён. Blink при желании
   впишет его обратно сам.

6. **Dev-зависимости линтера** (`@eslint/js`, `globals`,
   `typescript-eslint`, плагины) не перечислены в package.json — так было
   и в оригинале (в песочнице Blink они предустановлены). На своём
   хостинге `npm run build` работает без них; упадёт только `npm run
   lint`, если эти пакеты не доставить.

## Важно про данные

Импорт zip в Blink создаёт НОВЫЙ проект: код переедет, а база данных
(chat_messages, tasks), логины Blink Auth (djamilya@n1s.local) и
настройки RLS живут в старом проекте p69j91xs и НЕ переносятся.
Поэтому применять фиксы для живого приложения по-прежнему правильнее
через Code-вкладку существующего проекта.
